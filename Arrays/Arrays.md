# Arrays

## 1. Basics

Array ek aisi data structure hai jisme hum ek hi naam ke andar multiple values ko sequence (line-wise) mein store karte hain.

- **Index**: Array hamesha `0` (zero) se start hota hai.
- **Size**: Array ka size zyadatar programming languages mein fixed hota hai.

---

## 2. Basic Operations

In operations ko practice karna important hai:

### 🔹 Traversing
Pura array ek baar read karna (loops ka use karke).

### 🔹 Insertion & Deletion
Kisi element ko beech mein add ya remove karna.  
> Is process mein time lagta hai kyunki baaki elements ko shift karna padta hai.

### 🔹 Reverse an Array
Array ko ulta karna.

---

## 3. Interview ke Favorite Questions

Interviews mein theory se zyada logic-based questions aate hain. In topics ko zaroor prepare karein:

### Searching
- **Linear Search**: Ek-ek element check karke dhoondhna.
- **Binary Search**: Sirf tab use hota hai jab array sorted ho.

### Sorting
Array ko ascending order (chhote se bade) mein arrange karna:
- Bubble Sort
- Selection Sort
- Quick Sort

### Find Maximum / Minimum
Array ka sabse bada aur sabse chhota number nikalna.

### Subarrays
Array ka ek chhota continuous hissa.
- Kadane’s Algorithm frequently poocha jaata hai.
